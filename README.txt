BIG BROTHER CIRCLE — Version 4 demo

QUICK START
1. Open index.html in a modern browser to try the demo.
2. Enter a username and choose Shop / Business, Job, or Study / Other Skill.
3. Tick tasks and write notes. Progress is saved in this browser/device.

IMPORTANT LIMITATIONS
- This is a prototype, not a secure production login. It does not save or verify passwords; do not enter a real password or sensitive information.
- Progress uses browser localStorage and is not synced between devices. Clearing browser data can erase progress.
- Reminder times are saved as preferences only. Automatic/background notifications are not configured.
- To install as a PWA, upload the files to an HTTPS host, then open the hosted site in Android Chrome and use menu > Add to Home screen / Install app (wording varies).
- A real account system, secure login, cloud sync, and scheduled notifications require backend/authentication and notification setup (for example, Firebase plus a hosting service).
